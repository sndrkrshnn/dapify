# ClassiPod fork change list

Upstream base: ClassiPod `2.1.0` (see `UPSTREAM-README.md`, `LICENSE`).
Generated files (`lib/l10n/generated/`, `GeneratedPluginRegistrant.*`,
`untranslated_messages.json`) are regenerated by Flutter and are not part of
the diff.

## New files

| File | Purpose |
| --- | --- |
| `android/app/src/main/kotlin/com/adeeteya/classipod/MainActivity.kt` | HOME activity; haptics/screen/power/battery native bridge |
| `lib/core/services/battery_level_service.dart` | `ACTION_BATTERY_CHANGED` battery level + live provider |
| `lib/core/services/haptics_service.dart` | Native haptic MethodChannel, 35 ms detent throttle |
| `lib/core/services/power_status_service.dart` | External-power stream provider |
| `lib/core/services/system_integration.dart` | Back/volume forwarding, AOD scheduling, screen events |
| `lib/features/lock_screen/` | Album-art lock screen (widget + controller) |
| `lib/features/volume_hud/` | Graphite volume HUD (widget + controller) |

## Modified files

| File | Change |
| --- | --- |
| `android/app/build.gradle.kts` | `applicationId` overridden by `-PdapApplicationId`; release signing falls back to debug when `key.properties` is absent |
| `android/app/src/main/AndroidManifest.xml` | `MAIN`/`LAUNCHER`/`HOME`/`DEFAULT` on `.MainActivity`; `singleTask`; `fullSensor` |
| `android/gradle.properties` | 3 GB Gradle heap for the 8 GB build host |
| `lib/classipod_app.dart` | Mounts `SystemIntegrationHost`, lock screen, volume HUD |
| `lib/core/constants/constants.dart` | DAP constants (settings URI, click-sound volume, haptic pulse timings) |
| `lib/core/constants/assets.dart` | `uiFont` constant (DAP Sans) replacing the proprietary Helvetica asset name |
| `lib/core/models/shared_preference_keys.dart` | DAP setting keys (AOD, haptics, click sound, volume mode) |
| `lib/core/services/click_sound_service.dart` | Fixed 0.26 volume for the click sample |
| `lib/features/app_startup/controllers/app_startup_controller.dart` | Launch flow for the DAP boot path |
| `lib/features/device/services/device_buttons_service_provider.dart` | Detent + tap dispatch, haptics/sound sync |
| `lib/features/device/widgets/device_controls.dart` | Wheel geometry (single fixed medium size) |
| `lib/features/device/widgets/device_frame.dart` | Silk-screened SETTINGS key on the lower bezel |
| `lib/features/device/widgets/device_screen.dart` | DAP layout (portrait/landscape) |
| `lib/features/menu/models/split_screen_type.dart` | Remove donate split screen |
| `lib/features/menu/screens/split_screen_placeholder.dart` | DAP menu rows |
| `lib/features/now_playing/screen/now_playing_screen.dart` | Tappable shuffle/loop icons, loop cycle |
| `lib/features/settings/*` | Remove click-wheel-size setting; DAP settings row |
| `lib/features/status_bar/*` | Battery percentage from `ACTION_BATTERY_CHANGED` |
| `pubspec.yaml` | `DAPSans` font family (TeX Gyre Heros) instead of proprietary Helvetica |

## Removed files

| File | Reason |
| --- | --- |
| `lib/features/settings/models/click_wheel_size.dart` | Click-wheel size setting removed |
| `assets/fonts/Helvetica.ttf`, `assets/fonts/Helvetica-Bold.ttf` | Proprietary Linotype Helvetica; replaced by DAP Sans |
